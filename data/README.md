# Dataset setup

This project uses the **Jigsaw Toxic Comment Classification Challenge** dataset.

Download the competition data from:

https://www.kaggle.com/c/jigsaw-toxic-comment-classification-challenge

Extract the training data so that `train.csv` is somewhere inside:

```text
data/jigsaw-toxic-comment-classification-challenge/
```

The project searches recursively for `train.csv`, so an additional subfolder
created by extraction is fine.

The dataset is intentionally not included in this repository.
